# 技术说明

## 1. 模块划分

| 模块 | 职责 |
| --- | --- |
| `timeline.py` | JSON 解析、嵌套片段组递归展平、毫秒整数规范化、语义校验（起止、重叠、视频范围） |
| `wsola.py` | 变速不变调核心（WSOLA），含一次性处理与流式 `StreamingWSOLA` 两个入口 |
| `audioio.py` | WAV 校验/探测、分块读取、单片段适配（比例钳制、精确长度保证） |
| `mixer.py` | 流式时间轴混音器，分块读背景、惰性打开片段、配音增益与限幅 |
| `ffmpeg_utils.py` | FFprobe 探测、背景音轨抽取/静音合成、最终 MP4 混流封装 |
| `processor.py` | 单语言流水线与多语言线程池编排（并发上限、单任务内存保护） |
| `report.py` | 按语言分组的 JSON 报告、统一状态词汇、退出码映射 |
| `cli.py` / `__main__.py` | 命令行入口 |
| `logging_utils.py` | 线程安全的结构化错误/警告日志（控制台 + `error.log` + 报告内嵌） |

## 2. WSOLA 变速不变调

采用波形相似重叠相加（WSOLA）：

- 分析窗 40ms，合成跳 20ms，最大对齐搜索范围 ±15ms。
- 每帧在理想分析位置邻域内，以归一化互相关选择与“上一帧自然延续”
  最相似的候选帧，保证输出在固定合成网格上相位连续。
- 自然延续参考位于已选分析位置 + 一个合成跳 `Ss = Sa / ratio`，
  这是避免相位漂移的关键。
- 周期信号存在多个等价相关峰，tie-break 选择绝对偏移最小者，
  防止锁定到远处周期而产生音高漂移。
- 互相关用局部 FFT 计算，FFT 尺寸只取决于搜索邻域（与文件总长无关），
  实测约 200–600 ms 处理耗时 / 秒音频。
- 输出最后按 `round(源帧数 * ratio)` 精确补齐或裁剪，采样率与声道数不变。

音高保持验证（220Hz 谐波信号，抛物线插值测基频）：比例 0.5–2.0 范围内
漂移均小于 4 音分（cents），人耳不可察觉。

## 3. 时长适配与边界钳制

- 请求比例 = 目标时长 / 原始时长（按各自采样率换算帧数）。
- 超出片段 `ratio_range` 时钳制到边界，报告 `boundary_clamped=true`
  并写警告；此时片段无法完全填满时间轴窗，末端以静音补齐，不影响其它片段。
- 单片段超过 `--max-segment-seconds` 视为内存保护错误，跳过并占位。

## 4. 多语言与并发/内存控制

- 各语言独立适配，但对齐同一份时间轴，保证跨语言位置一致。
- `ThreadPoolExecutor(max_workers=--workers)` 限制并发语言数。
- 适配按单片段进行；混音器以 `--block-seconds` 分块流式处理，
  片段文件句柄惰性打开、窗口结束即关闭，峰值内存与片段总数解耦。
- 5.5 分钟、110 段、双语言实测峰值常驻内存约 204MB。

## 5. 混流封装与音画同步

- 背景音轨由 FFmpeg 统一重采样到目标采样率/声道；源无音轨时合成等长静音。
- 片段起始样本 = `round(start_ms * sample_rate / 1000)`，与时间轴严格对齐。
- 混合 WAV 以 PCM16 流式写出，再与原视频封装：视频流 `-c:v copy` 直拷
  （时间戳原样保留），音频 AAC，显式 `-t` 限定到视频时长，不使用 `-shortest`。
- 同步精度专项测试（在已知时间点放置 1kHz 脉冲，解码后定位起始样本）：
  最坏误差 0.06ms，远优于 10ms 验收线。

## 6. 异常处理与恢复

可恢复（跳过该片段、保留静音占位、继续后续）：

- 配音文件缺失、非 `.wav`、WAV 无法读取/为空
- 时间轴片段起止倒置、与相邻片段重叠、超出视频时长
- 片段超出内存保护上限

不可恢复（终止并返回非零退出码 4）：

- 时间轴 JSON 解析失败、根结构错误、缺少必填字段、时间非整数毫秒
- 源视频缺失、无法探测或无视频流
- 校验后无任何有效片段

## 7. 处理报告

`report.json` 顶层含 `summary`（含跨语言统一的 `status_values` 词汇表）
与 `languages` 数组。每个片段记录：原始/适配后时长、请求/应用比例、
是否触发边界、是否静音占位、错误与警告。语言级状态取值固定为
`success` / `partial_success` / `failed`，各语言完全一致。

## 8. 确定性

- 样本由固定公式 + 固定种子 RNG 合成，重复运行 WAV 内容一致。
- WSOLA 无随机数；tie-break 使用确定性的最小绝对偏移规则。
- 所有处理参数由输入与命令行显式决定，不依赖任何硬件基准。

## 9. 实际验证结果

| 验证项 | 结果 |
| --- | --- |
| 单元 + 集成测试 | 39 passed |
| WSOLA 时长精度 | 输出帧数 = `round(源帧数 × ratio)`，误差 0 样本 |
| WSOLA 音高保持 | 比例 0.5–2.0，基频漂移 < 4 cents |
| 音画同步 | 最坏 0.06ms（要求 ≤ 10ms） |
| 缺失/非 WAV/重叠/倒置 | 跳过 + 静音占位 + 错误日志，退出码 2 |
| JSON 解析失败/视频缺失 | 终止，退出码 4 |
| 长场景 | 5.5 分钟、110 段、双语言，峰值 RSS ≈ 204MB，正常产出 |
| 报告 | 按语言分组，状态词汇跨语言一致 |

## 10. 局限与说明

- 当前内存保护以单片段时长为界；分钟级超长单条配音可改用
  `StreamingWSOLA` 的分块 overlap-add 路径（类已提供，默认流水线按
  对白片段粒度调用一次性接口以获得最佳连续性）。
- 视频流采用直拷，要求源视频本身可被 MP4 容器承载；如需转码可在
  `ffmpeg_utils.mux_mixdown` 中调整 `vcodec`。
