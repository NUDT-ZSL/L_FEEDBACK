# 技术设计

## 1. 总体结构

渲染器是单进程 CPU 管线：

1. 确定性生成或读取高度场/材质权重。
2. 建立 256×256 顶点、130,050 个三角形的规则网格。
3. 使用同一套世界空间光源参数构建 2048×2048 正交光源深度图。
4. 将地形三角形变换到相机齐次裁剪空间，逐平面裁剪。
5. 用屏幕空间重心坐标遍历三角形，透视校正插值世界位置和法线。
6. 按像素读取三层材质权重，归一化后混合材质。
7. 3×3 PCF 计算阳光可见性，与材质基础着色合成。
8. 以 64×64 像素块为单位比较投影签名，只重绘覆盖发生变化的块。
9. 原子写出 PNG 和稳定格式 JSON；完整渲染后写快照。

## 2. 数据与网格

高度场由多层确定性 value noise、低频 fBm、山脊和独立山体组合而成。材质权重由高度、坡度和确定性颗粒噪声生成：

- 草地：低海拔、缓坡；
- 岩石：中高坡度；
- 雪：高海拔且相对平缓；
- 默认数据中额外放置 6×6 全零权重区域，用于覆盖 `MATW_ZERO`。

顶点法线由高度场中心差分得到。网格的每个四边形拆成两个共享对角线的三角形。

## 3. 投影、裁剪与光栅化

相机使用右手坐标系、4×4 透视矩阵和 `lookAtRH`。三角形先在齐次空间对六个视锥平面执行 Sutherland-Hodgman 裁剪：

- `x >= -w`
- `x <= w`
- `y >= -w`
- `y <= w`
- `z >= -w`
- `z <= w`

裁剪结果再执行透视除法和屏幕映射。每个像素使用中心 `(x+0.5, y+0.5)` 计算归一化重心坐标：

- 深度：屏幕空间重心线性插值 NDC 深度；
- 世界位置和法线：用 `1/w` 加权进行透视校正插值；
- 深度测试使用严格的小于比较；
- 允许边界上的极小负重心值，避免共享边因浮点误差产生漏光。

所有三角形使用相同的大地坐标和索引，不启用背面裁剪，因此地形内部不会因绕序误判出现破洞。

## 4. 阴影坐标系与偏置

主着色和阴影贴图共用同一个 `ShadowProjection.viewProjection`：

1. 光源位置由固定传播方向反推；
2. 用地形包围盒八个角点求光源视图空间正交范围；
3. 正交投影的 near/far 覆盖整个地形；
4. 阴影贴图从该矩阵渲染；主着色把世界点送入同一矩阵计算 UV 和接收者深度。

阴影贴图固定 2048×2048，深度以光照 NDC 深度映射到 `[0,1]`。

`--bias-texels` 的语义是“接收者在光源纹素空间中的自阴影偏移”：

- 沿几何法线移动 `biasTexels * worldTexelSize`，其中 `worldTexelSize` 由光源正交范围和 2048 分辨率算出；
- 额外深度 epsilon 为 `clamp(0.75 + 0.125 * biasTexels, 0, 2)` 个深度纹素；
- 主着色仍使用未偏移的世界坐标和材质，只把偏移用于阴影查询。

单纯在深度轴加 2/4 纹素会在地形斜面上产生很大的世界深度偏置，导致投影阴影质量明显下降；法线方向偏移能在不牺牲整片投影阴影的前提下消除自阴影 acne。验收图中的 `bias2_*` 和 `bias4_*` 分别来自两个偏置值。

PCF 固定使用 3×3 个采样点，默认半径为 8 个阴影纹素。每个像素用确定性哈希旋转采样网格并加入亚纹素抖动，再以 bilinear 阴影深度读取和归一化权重求和。这样保持每像素 9 次 PCF 采样，同时避免规则 3×3 网格产生清晰的九级阶梯边界。

## 5. 材质与光照

每个材质参数包含反照率、高光指数和粗糙度：

| 材质 | 反照率 | 高光指数 | 粗糙度 |
|---|---|---|---|
| 草地 | `(0.20, 0.47, 0.12)` | 28 | 0.72 |
| 岩石 | `(0.39, 0.38, 0.34)` | 52 | 0.52 |
| 雪 | `(0.87, 0.92, 0.97)` | 90 | 0.25 |
| 默认回退 | `(0.50, 0.45, 0.39)` | 34 | 0.68 |

权重贴图使用 bilinear 采样。权重和大于 `1e-6` 时归一化，再线性混合反照率、高光指数和粗糙度；和为零时使用默认材质，并累计 `MATW_ZERO` 警告。

硬阴影和软阴影调用同一个 `shadeSurface`：

- 环境光、天空/地面半球光、漫反射、Blinn-Phong 高光都由相同材质参数计算；
- 阴影模式只改变传入的阳光可见性；
- `N·L <= 0` 的区域标记为背光，不执行阴影采样，保留环境光和冷色补光，不会渲染为全黑。

## 6. 增量重绘

画布分成 16×12 个 64×64 像素块。每帧先不写颜色，而是：

1. 投影并裁剪所有地形三角形；
2. 对每个覆盖块累计一个投影签名；
3. 签名包含三个顶点的屏幕坐标（量化为 1/64 像素）、NDC 深度和三角形编号；
4. 用计数、两个独立哈希和、异或摘要组成顺序无关的块签名；
5. 与上一帧签名相同的块直接复用颜色缓冲和深度缓冲。

阴影模式、深度偏置或 PCF 半径改变时强制整帧重绘，避免错误复用不同着色状态的像素。相机平移时，天空和投影覆盖未变化的块保持不动，地形覆盖变化的块重新清空并光栅化。

增量验收序列为：

- 第 0 帧全量；
- 第 1 到 5 帧每次水平平移 0.65 世界单位；
- 第 6 帧大幅回退到初始位置；
- 另做一次同参数全量渲染作参考。

验收程序逐像素比较最终增量帧和全量帧，并允许每通道最多 1 的 8 位颜色误差。若超过容差，程序只会重绘超差像素所在块，并把修正块数计入总量。

## 7. 快照

每次完整渲染后写入版本化快照，包含：

- 相机 eye/target、yaw、pan、FOV、near/far；
- 光源方向；
- 阴影图尺寸、偏置、阴影模式；
- 种子和数据哈希。

启动 `render` 时若快照存在且版本为 3，恢复相机和光源；显式命令行参数优先。版本不匹配、JSON 损坏、字段缺失或数值非法时忽略快照并继续初始化，不会抛出未捕获异常。快照中的相机数值保留 9 位小数，保证恢复后渲染结果逐字节一致。

## 8. 确定性、报告与错误

同种子、同参数、无 `--include-wall-time` 时：

- 数据生成完全确定；
- 三角形顺序、采样哈希和阴影抖动完全确定；
- STB 压缩参数固定；
- JSON 键顺序、浮点位数和列表顺序固定；
- `render_time_ms` 使用固定工作量模型，而不是不可复现的墙钟时间。

业务错误统一映射为整数退出码和包含 `code/message/exit_code` 的 JSON。PNG 使用同目录临时文件 + 原子替换。取消检查同时支持 Ctrl+C 和确定性的三角形计数触发，取消发生在输出发布之前。
