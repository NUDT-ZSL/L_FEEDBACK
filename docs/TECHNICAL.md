# 技术说明

## 1. 帧结构与指令缓冲

`Renderer::render` 每帧执行以下顺序：

1. 由整数 `tick` 计算骨骼全局姿态和 `skin = poseGlobal * inverseBind`。
2. 对所有网格执行一次 CPU 蒙皮，生成该帧共享的 `FrameVertex`。
3. 由相机视锥查询均匀网格，得到可见单元集合和可见面索引。
4. 为方向光 2 级级联及 2 个点光源的 6 个立方体面生成深度图。
5. 记录指令缓冲：
   - 不透明面按 `(stateKey, materialId, faceId)` 排序后合并成材质批次。
   - 透明面按相机空间深度降序、材质 ID 升序、全局面 ID 升序排列。
   - 线框模式记录一个线框面批次。
6. 执行指令缓冲，完成光栅化和浮点线性颜色混合。
7. 对线性颜色做色调映射和 sRGB 编码，得到 8 位 RGB 帧缓冲。

阴影图根据动画 tick 缓存；相机旋转/缩放不改变固定世界空间光源的阴影图，因此不会在暂停时重复生成。

## 2. 坐标、投影与光栅化规则

- 使用左手坐标系，D3D 深度范围 `z_clip / w_clip in [0,1]`。
- 相机投影为 `Mat4::perspectiveD3D`；视图为 `lookAtLH`。
- 裁剪平面：`-w <= x <= w`、`-w <= y <= w`、`0 <= z <= w`。
- 裁剪采用 Sutherland-Hodgman，在齐次空间线性插值全部顶点属性。
- 屏幕映射：
  - `sx = (ndc.x * 0.5 + 0.5) * width`
  - `sy = (0.5 - ndc.y * 0.5) * height`
- 像素中心固定为 `(x + 0.5, y + 0.5)`。
- 外部顶点按“从外侧观察为逆时针”生成；在左手 D3D 相机与 Y 向下屏幕空间中，正面使用屏幕有向面积 `> 0` 判定。
- 覆盖边采用包含规则，不额外偏移采样点。共享边可能产生相同深度的覆盖，但深度规则和绘制顺序仍确定。
- 深度测试为 `z <= depthBuffer[x,y]`；近裁剪已保证 `0 <= z <= 1`。
- 深度写入只在 `depthWrite=true` 时执行；透明材质读深度但不写深度。
- 屏幕重心坐标用于取得 `z`，其他属性使用透视校正：

```text
denom = sum(bary_i / w_i)
attr  = sum(bary_i * attr_i / w_i) / denom
```

## 3. 骨骼蒙皮

- `Vertex` 固定存储 4 组 `boneIndices/boneWeights`。
- 生成器保证权重非负、归一化，并拒绝越界骨骼索引；测试逐顶点检查。
- 顶点阶段对位置、法线、切线做线性混合；位置经完整骨骼矩阵变换，法线和切线经旋转部分变换后归一化。
- 骨骼动画仅依赖整数 tick：`time = tick / 30.0`。同一 tick 的骨骼矩阵和蒙皮结果逐位相同。
- 层级包含 root、spine、chest、head、双臂、双腿及足部。

## 4. 法线贴图与切线空间

- 法线图由周期函数生成，分辨率 `256x256`，重复包裹。
- 采样使用双线性过滤；坐标通过正模运算包裹，支持负 UV 和跨越经度接缝。
- 双切线为 `B = cross(N, T) * tangent.w`。
- 右臂和右腿使用镜像 U 坐标，同时把切线方向取反并设置 `tangent.w = -1`，保证镜像区域的切线基方向正确。
- 法线图解码后按材质 `normalStrength` 扰动世界法线；双面透明材质会根据视线翻转法线。

## 5. 光照与阴影

光源：

- 1 个方向光。
- 2 个点光源。

方向光阴影：

- 2 级级联，每级 `1024x1024`（可配置）。
- 级联范围分别覆盖半径 4.3 和 9.0 的世界空间区域。
- 按片元相机空间深度与 `cascadeSplit = 7.0` 选择级联。

点光源阴影：

- 每个点光源 6 个立方体面。
- 单面默认 `256x256`（可配置）。
- 通过主方向轴选择面，再用该面的 `viewProjection` 得到阴影 UV 和投影深度。

过滤与偏移：

- `3x3` PCF，共 9 次深度比较。
- 方向光采用法线偏移 `0.018` 世界单位，深度偏移 `0.0012 + (1-NdotL)*0.0045`。
- 点光源采用法线偏移 `0.012` 世界单位，深度偏移 `0.0018 + (1-NdotL)*0.0075`。
- 阴影图默认清为 `1.0`，边界外按受光处理。

## 6. 均匀网格与视锥剔除

- 网格单元边长 `1.25` 世界单位。
- 静止绑定姿态三角形按包围盒插入所有相交单元，并额外扩展 `0.42` 单位容纳小幅动画位移。
- 每帧用六个视锥平面测试单元 AABB，重建 `visibleCells`。
- 从可见单元收集面索引并去重，然后对蒙皮后的三角形 AABB 做精确视锥测试。
- 日志输出：

```text
[cull] total=... grid_candidates=... visible=... ratio=... cells=...
```

`ratio = 视锥可见三角形数 / 全部三角形数`。

## 7. 材质排序

不透明键：

```text
(material.stateKey, materialId, globalFaceId)
```

连续同材质三角形合并为一条绘制指令，减少状态切换。

透明键：

```text
(-cameraSpaceDepth, materialId, globalFaceId)
```

`cameraSpaceDepth = dot(triangleCentroid - cameraPosition, cameraForward)`。

排序比较器具有全序键，避免浮点深度相等时出现不稳定次序。

## 8. 色彩与导出

- 光照与透明混合在线性颜色空间完成。
- 解析阶段使用 `c = c / (1 + c)` 压缩高光，再用标准 sRGB 分段传输函数编码。
- Win32 GDI 显示和导出共用同一个 `Image` 的 8 位 RGB 数据。
- PPM(P6) 直接写 RGB，BMP 写自下而上的 BGR 行并按 4 字节对齐。
- 导出后重新打开文件，校验 magic、尺寸、位深、压缩方式、像素偏移和负载长度。

## 9. 确定性约束

- 不使用多线程、随机数或 wall-clock 时间参与姿态/着色。
- 所有浮点运算使用当前可执行文件的固定顺序；MSVC 明确使用 `/fp:precise`。
- 排序键唯一且稳定。
- 固定 tick 的蒙皮、阴影图、可见面集合和输出哈希在重复运行中一致。
